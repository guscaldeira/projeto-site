# Currículo Online - Gustavo Caldeira

Este repositório contém o meu currículo profissional transformado em uma página web. O projeto foi desenvolvido como um laboratório prático durante o curso de **Git e GitHub**, com o objetivo de aplicar fluxos de trabalho reais e boas práticas de versionamento.

##  Tecnologias Utilizadas
- **HTML5**: Estruturação semântica de conteúdo.
- **CSS3**: Estilização moderna com foco em legibilidade e design limpo.
- **Git & GitHub**: Controle de versão e deploy.

## Estrutura do Repositório

Para manter o projeto organizado, utilizei uma estrutura modular:

- **index.html:** Página principal com meu perfil e habilidades.

- **/estilos:** Contém o arquivo style.css que gerencia a identidade visual (cores e layout).

- **/Imagens:** Centraliza as mídias e a página dedicada ao meu Certificado de Ensino Médio.
